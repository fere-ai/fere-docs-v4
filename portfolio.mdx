The **Portfolio** page (`/portfolio`) is your book of accounts — Main plus every strategy wallet — with a combined net worth that does not change when you drill into a single wallet.

## What You See on the Book

- **Total net worth** — Main + active strategies (+ funded closed strategies).
- **Realized PnL** and **traded volume** — portfolio-level figures.
- **Allocation** — how value is split across Main and strategies.
- **Accounts list** — each row shows balance and live PnL.

Day one (nothing funded yet) shows a short **Deposit** / **Browse strategies** prompt above the accounts list. Main still appears so you can open it and deposit.

## Open a Wallet (Drawer)

Tap an account row to open a **wallet drawer**:

- **Desktop** — glass panel from the right.
- **Mobile** — bottom sheet.

The book stays underneath. Close with **X**, Escape, or the backdrop.

### Main wallet

- Balance, **Add Funds**, and wallet details (EVM + Solana cluster → Your Wallets).
- Venue lens (All / Tokens / Polymarket / Hyperliquid / Yield) filters what is below.
- **Open Positions** — live holdings (sell / redeem where available).
- **Trade History** — cross-venue activity; scrolls to load older pages (no “Load more”).

### Strategy wallet

- Isolated addresses, **Fund** / **Withdraw**.
- Empty strategies show an empty callout; Fund from Main to activate.
- Positions for that strategy only (no separate strategy trade-history feed yet).

## Fund / Deposit / Withdraw Without Opening the Drawer

On each account row:

| Account | Actions |
| --- | --- |
| Main | **Deposit** → same Add Funds flow as elsewhere |
| Strategy | **Fund** / **Withdraw** → strategy transfer modals |

These open the modal directly; they do not open the drawer.

## Hide Dust & Unverified

The same hide-dust / hide-unverified toggles used in the wallet panel apply here. If filters zero every visible balance, the empty prompt may appear — but the **accounts list stays** so you can still open Main for wallets and history.
